# Osaka-Data-Quest-2026

# 大阪データコンテスト 2026：地域文化発信・回遊促進統合型アプリ企画

## 1. プロジェクト概要 (Project Overview)
本プロジェクトは、「大阪データコンテスト 2026」における地域課題解決の取り組みです。提供いただいた**南海電気鉄道の運行データ**および**沿線商店の販売データ**にオープンデータを掛け合わせ、大阪が直面する**「人口流出」**という構造的課題に対するデータドリブンなソリューションを提案します。

南海電鉄の「グレーターなんば」計画や空港線の旅客数急増という成長機会に着目し、観光客の流入を一過性の通過で終わらせず、地域内での回遊・消費拡大、ひいては地域文化の活性化と定住魅力の向上（人口流出の抑制）へとつなげる**統合型アプリケーション**を企画・開発しました。

---

## 2. データ分析による現状把握と課題発見 (Data Analysis & Insights)
電車の運行データおよび商店の販売データを可視化し、分布の特徴や相関を分析した結果、以下の構造的な課題が明らかになりました。

* **南部地域の「通過点化」：** 空港線の旅客数（インバウンド・観光客）は急増しているにもかかわらず、大阪南部地域の商店消費は十分に改善していない。
* **体験価値と情報発信の分断：** 観光客の評価が低下傾向にあるほか、地域の魅力や店舗情報を適切かつ一元的に届ける情報チャネルが存在しない。

---

## 3. 企業戦略分析とビジネスフレームワークの統合 (Business Strategy & Framework)
プロジェクトの方向性を明確にし、データ分析の結果を事業価値へと昇華させるため、**南海電鉄の財務諸表および中期経営計画**を分析しました。

* **財務・経営戦略の評価：** 南海電鉄の収益・損失構造と成長性を評価した結果、同社は大阪を縦断する強固な交通インフラを基盤に、「グレーターなんば」計画の推進および沿線の地域文化活性化へ重点的に投資していることを確認しました。
* **フレームワークによるストーリー統合：** **PEST分析・3C分析**および**ビジネスモデルキャンバス（Business Model Canvas）**を活用し、企業の投資戦略とデータから見えた地域課題を一本のロジックとして統合しました。
  * **戦略的適合性：** 空港線旅客増という外部機会（Opportunity）に対し、南海電鉄の沿線インフラ（Strength）を掛け合わせ、単なる「移動手段」から「沿線全体の消費・文化体験プラットフォーム」への転換を設計。
  * **人口流出抑制のロジック：** 観光客の回遊と消費拡大 → 地元商店・企業の収益改善 → 雇用創出と街の魅力向上 → 若年層・ファミリー層の定着という経済循環モデルを構築。

---

## 4. 提案ソリューション：統合型地域文化・回遊アプリ (Proposed Solution)
定量分析およびマーケティングリサーチの結果に基づき、観光客向けに以下の機能を備えた統合型サービスを提供します。

* **AIによるパーソナライズド・ルート自動生成：** 観光客が入力した興味・キーワードに基づき、南海電鉄の交通インフラを軸とした最適な観光・文化体験ルートをAIが自動作成。
* **地域情報の一元化と文化発信：** 分断されていた南部地域の商店情報、イベント、地域文化コンテンツを単一プラットフォームに集約し、観光客の満足度向上と地域消費の拡大を同時に実現。
